# 블러·모자이크 영역 (2026-11-09)

## 사용
- 툴바 `블러·모자이크` → 사진 위를 드래그해 타원을 그린다. Shift는 정원, 클릭만 하면 사진 짧은 변의 1/5 지름 원, Esc는 취소. 하나를 그리면 그리기 모드가 끝나고 새 영역이 선택된다.
- 영역은 스티커처럼 드래그 이동, 8방향 핸들로 자유 비율 크기 조절, 회전한다. 방향키(1px/Shift 10px)·Delete·Ctrl+D·undo/redo 모두 동작.
- 우측 `가림 효과`에서 블러(기본)/모자이크와 강도 1~100을 슬라이더나 수치로 바꾼다. 슬라이더 한 번 드래그는 undo 한 단계. 영역이 선택되지 않았을 때 바꾼 값은 다음에 그릴 영역의 기본값이 된다(세션 안에서만).

## 데이터·좌표
- `Scene.regions: BlurRegion[]` — 스티커와 같은 원본 논리 픽셀 좌표, 중심 (x, y), 너비/높이, 회전(도), `style: 'blur' | 'mosaic'`, `strength: 1~100`. 사진당 최대 50개.
- 영역은 **사진 픽셀만** 가린다. 스티커는 항상 영역 위에 그린다(겹침 순서 조정 대상 아님).
- 강도는 영역 짧은 변 기준: 블러 σ = 짧은 변 × 강도/100 × 0.15 (최소 1px), 모자이크 블록 = 짧은 변 × 강도/100 × 0.25 (최소 2px).
- 모자이크 블록은 사진 원점 격자에 맞춰 영역을 옮겨도 블록 경계가 흔들리지 않는다.

## 구현
- `src/shared/effects.ts`: 회전 타원 경계, 필요한 원본 범위(블러는 3σ 여백, 모자이크는 격자 셀 단위), 3패스 box blur(가장자리 clamp라 사진 테두리가 어두워지지 않음), 블록 평균 모자이크. 순수 함수라 단위 테스트로 검증.
- `src/renderer/regions.ts`: 원본 bitmap에서 필요한 범위만 읽어 패치를 만들고, 회전 타원으로 clip 한다. 미리보기(Konva)와 저장(`composePng`)이 같은 패치 함수를 쓰므로 결과가 같다. 저장은 원본 해상도 패치를 출력 크기로 그린다.
- 미리보기 패치는 영역 값이 바뀔 때만 다시 만들고(영역별 캐시), 드래그·변형 중에는 패치 대신 반투명 윤곽만 보인다.

## 검증 (macOS 26.3 arm64)
- 단위 5개: 경계·회전·사진 밖, 평탄 영역 보존·가장자리 비어둡게, 모자이크 평균·격자 고정, 원본 범위·강도, 장면 추가/수정/복제/삭제/한도/잘못된 값.
- E2E 1개: 실제 마우스로 그리기·Esc·이동·방향키·슬라이더 드래그 1회 undo, 2px 줄무늬 사진을 저장해 영역 안은 회색·밖은 원본 유지, 모자이크 블록 동일 색, 삭제 undo.
- Windows 수동 확인 대기.

## 가림 도구 흐름 개편 (2026-11-09)
문제: 영역 하나를 그리면 그리기 상태가 꺼져 여러 곳을 가리려면 매번 툴바 버튼을 다시 눌러야 했음. 원형만 있어 사진 가장자리·모서리를 가리기 어려웠음.

결정:
- 오른쪽 탭 `스티커 | 가림 | 보정`. **가림 탭이 곧 도구**이며 다른 탭·Esc·툴바 `블러·모자이크` 버튼·`B` 키로 켜고 끔. 영역을 그린 뒤에도 켜진 채로 남음.
- 도구가 켜져 있으면 빈 곳 드래그 = 새 영역, 기존 영역 클릭 = 선택·이동·크기·회전. 드래그 없이 클릭하면 선택만 해제(실수로 기본 원이 생기던 동작 제거). 스티커는 잠김. 도구가 꺼져 있으면 반대로 영역이 잠김. 탭을 바꾸면 다른 층의 선택은 해제.
- 모양 `원형 | 사각형`(`BlurRegion.shape`, 없으면 원형). 사각형 경계는 회전한 네 모서리로 계산하고 미리보기·저장 모두 같은 `regionPath`로 자름.
- 드래그 좌표는 사진 범위로 고정되므로 **사진 밖 여백에서 시작하면 사진 끝·모서리에 정확히 맞음**. Shift는 정원·정사각형.
- 선택이 없을 때 모양·방식·강도는 다음 영역 기본값, 선택이 있으면 그 영역에 적용. `모두 지우기`는 실행 취소 가능한 한 단계.
- 영역을 지우면 남은 영역 중에서만 다음 선택(스티커로 넘어가지 않음).
