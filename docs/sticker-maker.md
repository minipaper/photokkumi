# 스티커 만들기 (2026-11-21, 0.1.12)

사용자 요청: 블로그 공정위(경제적 이해관계) 표기 스티커를 앱에서 만들기. 결정(사용자): 툴바 별도 모드, 아이콘은 직접 그림(외부 아이콘 세트 미사용), 범위는 공정위·소제목·마무리 전부. 참고 캡처(`sample/`, OGQ 판매 작품)는 구성 방식만 참고했고 저장소에 넣지 않았다.

## 구조
- `src/shared/sticker-maker.ts`: 디자인 19종(공정위 10·소제목 6·마무리 3), 문구 43개(공정위 21·소제목 18·마무리 4), `[강조]` 표기 해석, 상태·요청 검증.
- `src/shared/sticker-icons.ts`: 직접 그린 24×24 선 아이콘 36종(패널 SVG와 캔버스 Path2D가 같은 path 사용).
- `src/renderer/sticker-draw.ts`: 측정한 상자(글자 줄·아이콘·도형)를 쌓아 그리고, 투명 여백을 잘라 PNG로 만든다. 미리보기·목록 카드·저장이 같은 함수.
- `StickerMaker.tsx`: 디자인·문구·내용·스타일 탭, 미리보기 바탕(흰색·투명·어두운 색), 내 스티커(최대 30, `pk.makerMine`), 마지막 상태 유지(`pk.maker`).
- 저장: `maker:save`가 출력 폴더에 `<이름>.png`(충돌 시 `_1`), `maker:library`가 라이브러리 분류 `공정위`/`소제목`/`마무리`에 추가. main은 PNG를 다시 해독·인코딩하고 스티커 한도(400만 화소)를 확인한다.
- 크기: 문장 글자 18/24/32/44px. 밝은 강조색은 글자에 쓸 때 자동으로 진하게.

- 미검증: Windows 실제 화면(글꼴 렌더링).
