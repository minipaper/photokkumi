# 썸네일 만들기 (2026-11-13~14, 0.1.8)

블로그 대표 이미지(1:1, 1080×1080)를 만드는 세 번째 작업 모드. 사용자 결정: 별도 탭, 1:1만 먼저(다른 비율은 나중), 템플릿은 많이(사진형 약 70%·카드뉴스 약 30%), 템플릿 바꿔 보기·색 테마·내 템플릿 저장 포함. 참고 이미지(`blog_thum.png`, Canva 유료 템플릿 모음)는 레이아웃 패턴만 참고했고 저장소에 넣지 않는다. 템플릿·장식은 앱 글꼴과 도형으로 새로 만들었다.

## 구조
- 썸네일은 사진 편집과 같은 편집기·장면(`Scene`)·undo를 쓰는 별도 세션(`THUMB_SESSION_ID = 'thumbnail'`). 배경(색 → 정사각형에 꽉 차게 자른 사진 → 어둡게)을 1080 비트맵으로 그려 편집기의 "사진" 자리에 두고, 그 위에 도형 → 스티커 → 글자를 그린다. 미리보기와 저장(`composePng`)이 같은 그리기 함수(`drawShape`·`drawText`)를 쓴다.
- 탭을 오가도 썸네일과 사진 편집의 편집 내용은 각각 남는다(앱을 켜 둔 동안). 닫을 때 둘 중 하나라도 저장 안 한 편집이 있으면 묻고, `저장`은 썸네일과 사진을 모두 저장한다.
- 처음 열면 첫 템플릿에 사진 편집에서 보던 사진을 배경으로 넣는다. 사진 넣기(툴바)·배경 탭·창에 끌어 놓기로 바꾼다.
- 저장: 출력 폴더에 `<배경 사진 이름>_thumb.jpg|png`(사진이 없으면 `썸네일_thumb`), 이미 있으면 `_1`… 형식은 툴바에서 고르고 기억한다(기본 JPG). main은 1080×1080인지 다시 확인하고 픽셀을 새로 인코딩한다(메타데이터 없음).

## 템플릿 (`src/shared/thumb-templates.ts`)
- 34개: 사진형 24(NEW POST·강조 한 줄·컬러 테두리·색 상자·형광펜·흰 액자·라벨·해시태그·아래 흰 상자·반투명 카드·원형 배지·감성 명조·손글씨·주아·예능 자막·어두운 띠·왼쪽 패널·위아래 분할·TOP 순위·여행 날짜·솔직 후기·말풍선·레트로·미니멀), 카드뉴스 10(메모지·스프링 노트·큰 원·테두리 카드·컬러 블록·말풍선·따옴표·줄 노트·동그라미 강조·큰 글자).
- 글자는 역할(`slot`: title·title2·kicker·sub·tag·handle…)을 가진다. 위치는 세로 묶음으로 정한다: 첫 글자의 y에서 아래로 간격을 두고 쌓고, `v`로 묶음 가운데·아래를 맞춘다. 그래서 줄 수가 바뀌어도 겹치지 않는다. 영역보다 넓은 글자는 맞을 때까지 줄인다. 선·고리·카드 같은 도형은 글자에 붙일 수 있다(둘레·위·아래).
- **템플릿 바꿔 보기**: 같은 역할의 글자 내용과 사진·확대·위치를 옮긴다. 제목 한 개 ↔ 제목+강조 줄은 마지막 줄을 나누거나 합친다. 스티커는 그대로 둔다. 카드뉴스는 사진을 숨기지만 선택은 남겨(배경 탭 `사진 보이기`) 사진형으로 돌아가면 다시 보인다.
- **색 테마** 10가지(노랑·주황·분홍·빨강·초록·민트·하늘·파랑·보라·갈색)와 `기본`(템플릿마다 정한 색). 템플릿의 강조색·글자색·연한 배경색은 테마에 연결되고(`themed`, `colorSlot`), 사용자가 직접 바꾼 색은 연결이 끊겨 테마를 바꿔도 유지된다. 고른 테마는 다음 템플릿과 목록 미리보기에도 적용된다.
- 목록 미리보기는 지금 넣은 사진(없으면 그려 낸 풍경)으로 그린다.

## 패널
- 템플릿: 전체·사진형·카드뉴스·내 템플릿, 색 테마, 미리보기 목록(이 목록만 스크롤).
- 배경: 사진 고르기·열기·빼기, 확대 100~400%, 좌우·위아래 위치, 어둡게 0~90%, 배경색.
- 글자: 사진 편집과 같은 글자 패널(빠른 스타일·내 스타일 포함). 왼쪽·오른쪽 정렬 글자는 내용이 바뀌어도 그 끝이 제자리에 있다(사진 편집 글자도 같음).
- 꾸미기: 도형(사각형·둥근 상자·원·테두리·선) — 채우기 색·불투명도, 테두리 색·두께, 모서리(50=알약), 그림자, 가로·세로 따로 크기 조절, 앞뒤 순서 — 와 스티커 라이브러리.
- **내 템플릿**: 지금 배경 모양(사진 제외)·도형·글자(내용 포함)·테마를 작은 미리보기와 함께 최대 30개 저장(`pk.thumbTemplates`, 앱 로컬 저장소). 적용할 때 지금 사진과 위치는 유지. 스티커는 저장하지 않는다.
- 좁은 창(960px 이하)에서는 모드 탭이 `사진·썸네일·GIF`로 줄어 툴바가 한 줄에 들어간다(Windows 맑은 고딕은 macOS 글꼴보다 넓어 0.1.8 첫 CI에서 760px 창 툴바가 넘쳤다).

## 검증 (macOS 26.3 arm64)
- 단위 11개(`tests/thumb.test.ts`): 템플릿 34개·비율·모든 팔레트에서 값 유효·역할 중복 없음, 카드뉴스 사진 숨김·테마 연결, 세로 묶음 배치(위·가운데·아래)·같은 줄 태그·정렬, 도형 붙이기, 내용 옮기기(나누기·합치기), 도형 편집·순서·삭제와 테마 연결 끊기, 테마 적용, 왼쪽 정렬 끝 유지, 레이아웃 적용 검증, 배경·도형·저장 요청·내 템플릿 검증.
- E2E 1개: 사진 열기 → 썸네일 탭(첫 템플릿·사진 배경), 템플릿 34/카드뉴스 10, 제목 바꾸고 템플릿 두 번 바꿔도 제목 유지, 초록 테마, 원 도형 추가·삭제·실행 취소, **1080 JPG 저장 후 상자 안(초록)·밖(20% 어둡게 한 사진) 픽셀 확인**, 잘못된 크기 저장 거부, 내 템플릿 저장, 편집 후 사진 편집 탭에서 닫기 → 저장 → `_thumb_1.jpg`, 재실행 후 내 템플릿 적용 시 제목 복원.
- 수동: 34개 템플릿을 차례로 바꿔 가며(내용 옮기기 포함) 겹침 없음, 1180×820·760×580에서 4개 탭 모두 우측 패널·툴바 가로 넘침 없음.
- 미검증: Windows 실제 화면(글꼴 렌더링·DPI), 아주 큰 사진을 배경으로 쓸 때 속도.
