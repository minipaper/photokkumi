# 글자 넣기 (2026-11-13, 0.1.6 · 0.1.7 정렬 아이콘 수정)

## 결정 (사용자 확인)
- 글꼴은 **앱 내장 OFL 글꼴 + 내 PC에 설치된 글꼴**을 함께 쓴다. 오프라인 앱이고 CSP로 원격 로딩을 막으므로 "웹폰트"는 CDN에서 받지 않고 **설치 파일에 넣는다**. 실행 중 내려받으면 인터넷이 없을 때 글꼴이 바뀌어 저장 결과가 달라진다.
- 내장 범위: **OFL 원문을 직접 확인한 인기 글꼴 15종**. OFL이 아닌 눈누 글꼴(G마켓 산스·카페24·리디바탕 등 자체 라이선스)은 넣지 않는다. 사용자가 PC에 설치하면 `내 PC 글꼴`에 나타나므로 그대로 쓸 수 있다.
- 입력: **우측 `글자` 탭의 입력칸**에서 고친다(사진 위 직접 입력 아님 — 한글 IME·회전·확대 상태에서도 안정적).

## 사용
- 툴바 `T 글자` 또는 `T` 키 → 사진 가운데에 `텍스트`가 생기고 입력칸이 선택된 상태로 열린다. 바로 입력하면 바뀐다. 다음 글자는 한 줄 아래에 생긴다.
- 사진 위 글자는 스티커처럼 끌어서 이동, 모서리 핸들로 크기(비율 유지), 위 핸들로 회전한다. 방향키·Shift+방향키·Delete·Ctrl+D·undo/redo 동일. 캔버스에서 글자를 누르면 `글자` 탭, 스티커를 누르면 `스티커` 탭으로 전환된다.
- 패널: 내용(여러 줄), 빠른 스타일 7종, 글꼴, 크기(px, 원본 기준), 굵게, 줄 정렬(왼/가운데/오른), 그림자, 글자색, 외곽선(색·두께), 배경 상자(색·불투명도·둥근 모서리).
- 빠른 스타일은 글꼴·크기는 두고 색·외곽선·상자·그림자만 바꾼다(흰 글자+검은 외곽선, 검은 글자+흰 외곽선, 노란 자막, 반투명 검은 상자, 흰 상자, 분홍+흰 외곽선, 그림자만). 미리보기 칩은 사진처럼 보이는 그라데이션 위에 그려 사진 위에서의 대비를 보여 준다.
- 선택이 없을 때 바꾼 스타일·글꼴은 다음 글자의 기본값이 되고, 마지막 스타일과 **크기(사진 짧은 변 대비 비율)**는 재실행 후에도 유지된다(`pk.textDefaults`, 앱 로컬 저장소). 그래서 해상도가 다른 사진에서도 자막 크기가 비슷하다.
- 입력·슬라이더·색 고르기는 한 번의 실행 취소 단위로 묶인다(입력칸을 벗어나거나 저장할 때 확정). 입력 중 Ctrl+S로 저장해도 저장 후 `수정됨`으로 돌아가지 않는다.

## 데이터·좌표
- `Scene.texts: TextItem[]` (사진당 최대 50개). `TextItem`은 원본 논리 픽셀 기준 중심 (x, y), 회전(도), `fontSize`(px), `text`(최대 500자), `style`, 그리고 측정한 상자 `width/height`.
- `style`: `font`(내장 id 또는 `system:<글꼴 이름>`), `bold`, `color`, `align`, `strokeColor`, `strokeWidth`(글자 크기의 0~30%), `boxColor`, `boxOpacity`(0~100, 0이면 상자 없음), `boxRound`, `shadow`.
- 상자 크기 = 가장 긴 줄 폭 + 2×(상자 여백 0.4em + 외곽선), 높이 = 줄 수×1.3em + 2×(0.2em + 외곽선). 빈 글자도 0.5em 폭을 유지해 잡을 수 있다. 핸들 크기 조절은 `fontSize`와 상자를 같은 비율로 바꾼다(`scaleText`, 4~4000px).
- 그리기 순서: 사진(보정) → 블러·모자이크 → 스티커 → **글자(항상 맨 위)**. 사진 밖으로 나간 부분은 미리보기·저장 모두 잘린다.
- 미리보기(Konva `Shape`의 sceneFunc)와 저장(`composePng`)이 같은 `drawText`를 호출한다. canvas 그림자 값은 변환을 무시하는 장치 픽셀이라 현재 변환 배율로 환산하고, 그림자 방향은 글자 기준 아래로 둔다. 외곽선은 채우기 전에 두 배 두께로 그려 바깥쪽만 보이게 한다.
- 저장 전에 모든 글자의 글꼴을 `FontFace.load`로 기다린다. 글꼴이 늦게 로드되면 캔버스가 다른 글꼴로 조용히 그리기 때문이다.

- **예약 글꼴 이름(RFN)**: OFL은 수정본(형식 변환·부분 글꼴 포함)에 예약 이름을 쓰지 못하게 한다. 그래서 글꼴 이름 자체가 RFN인 나눔·Pretendard·SUIT는 **배포본 그대로** 넣고, RFN이 없거나 이름과 무관한 글꼴(Noto의 RFN은 "Source")만 줄였다.
- 부분 글꼴 범위: 기본 라틴·라틴-1·문장부호·화살표·원문자·도형·기호(★♥♪)·CJK 문장부호·자모·완성형 11,172자·전각. **한자·가나는 뺐다.** 없는 글자는 프리텐다드 → 시스템 글꼴 순으로 대체된다(2,350자 글꼴의 드문 음절도 같음). 이모지는 시스템 이모지 글꼴로 그려진다.
- 크기: 25 MB(나눔 원본 ttf 16.6 MB 포함), LZMA 압축 약 12.6 MB → 설치 파일 약 13 MB 증가 예상.
- 재생성: `python3 -m venv .venv && .venv/bin/pip install fonttools brotli && .venv/bin/python scripts/prepare-fonts.py` (다운로드 캐시는 `.font-cache/`, 둘 다 gitignore). 스크립트가 OFL 원문이 아니면 중단한다.
- 눈누 인기 목록 중 내장한 것: 프리텐다드, 본고딕, 수트, 주아, 나눔고딕, 나눔명조, 고운바탕, 검은고딕. 그 밖의 OFL 후보(빗썸고딕, 페이퍼로지, 마루 부리, 나눔스퀘어, 꾸불림체 등)는 원 배포처 파일·라이선스 확인 후 추가할 수 있다.

## 보안
- 글꼴 파일은 renderer 번들(`out/renderer/fonts`, asar 내부)에서 `app://bundle/fonts/…`로만 제공한다. 프로토콜은 `/fonts/` 아래 `.woff2`·`.ttf`만 허용하고 그 밖의 확장자(OFL.txt 포함)는 거부한다. CSP에 `font-src 'self'`만 추가했다.
- PC 글꼴 목록은 Local Font Access(`queryLocalFonts`)로 읽는다. 권한 처리기는 **`local-fonts` 하나만**, 앱 창의 main frame이고 요청 출처가 앱 페이지(scheme+host 비교 — `URL.origin`은 `app://`에서 `'null'`이라 쓰지 않음)일 때만 허용한다. 나머지 권한은 그대로 모두 거부.
- PC 글꼴 이름은 CSS 글꼴 문자열에 들어가므로 따옴표·역슬래시·`;{}<>`·제어 문자·앞뒤 공백·120자 초과를 거부한다.

## 검증 (macOS 26.3 arm64)
- 단위 10개(`tests/text.test.ts`): 레이아웃(여러 줄·외곽선·상자·빈 글자), 정렬 기준선, 핸들 크기 조절과 한도, 스타일·항목·글꼴 참조 검증, 장면 추가·이동·크기·내용·복제·삭제·모두 지우기·undo, ID 충돌·50개 한도, 내장 글꼴 파일·OFL 동봉 일치, `local-fonts` 권한·글꼴 제공 경로.
- E2E 1개: `T` 키 추가 → 입력칸 포커스·바로 입력, 내장 글꼴 로드, 색·상자·외곽선·크기 undo/redo, 숫자 위치, **미리보기 캔버스와 저장 PNG의 같은 좌표가 모두 상자 색**, 상자 밖은 원본 유지, Delete·undo, 입력 중 저장 후 깨끗한 상태 유지, PC 글꼴 목록 로드. 전체 E2E 30개 통과.
- 수동: 1180×820·760×580에서 우측 패널 가로·세로 넘침 없음(최소 크기에서 숫자 위치 칸을 펼치면 글자 패널만 스크롤), 마우스 이동·모서리 크기 조절(80→112px) 확인.
- **Windows 검증 대기**: 맑은 고딕 등 PC 글꼴 목록·한글 이름 글꼴, 설치본에서 `app://bundle/fonts` 로딩, DPI 배율에서 그림자·외곽선 일치, 설치 파일 크기.

## 제한
- 글자는 사진 편집 세션 안에서만 유지된다(프로젝트 저장 없음). 다른 PC에서 이어 편집하지 않으므로 PC 글꼴이 없어지는 경우는 없다.
- 자동 줄바꿈·자간·행간 조절·곡선 글자·글자별 색은 없다(Enter로 줄을 나눈다). 글자는 스티커와 겹침 순서를 바꿀 수 없고 항상 위에 그린다.
- 내장 글꼴 대부분은 보통·굵게 두 굵기만 있다. 굵게 파일이 없는 글꼴(고운돋움·검은고딕·도현·주아·나눔손글씨)은 브라우저가 굵게를 합성한다.
