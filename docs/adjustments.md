# 사진 보정(필터) (2026-11-09)

## 사용
- 우측 패널 `보정` 탭: 노출·대비·채도·색온도를 슬라이더 또는 수치(−100~100, 0=원본)로 조절. 슬라이더 두 번 클릭은 0으로.
- 슬라이더 한 번 드래그는 undo 한 단계. `초기화`도 undo 가능.
- `모든 사진에 적용`: 현재 사진의 보정 값을 다른 모든 사진에 복사한다. 각 사진의 편집 이력에 한 단계로 기록되어 사진마다 실행 취소할 수 있고, 저장된 사진은 `저장 후 수정`으로 바뀐다.
- 탭 이름의 점(•)은 현재 사진에 보정이 적용됐음을 뜻한다.

## 정의
- 노출: 선형광에서 ±2 EV (`2^(값/50)`).
- 색온도: 선형광에서 R ×(1+0.4t), G ×(1+0.06t), B ×(1−0.4t), t=값/100.
- 대비: sRGB에서 0.5 기준, +100은 2배, −100은 0.2배.
- 채도: sRGB에서 Rec.709 휘도 기준 ×(1+값/100). −100은 흑백.
- 알파는 바꾸지 않는다. 0,0,0,0이면 픽셀을 전혀 건드리지 않는다(기존 픽셀 회귀 유지).

## 합성 순서
보정 → 블러·모자이크(보정된 픽셀을 가림) → 스티커(보정하지 않음). 미리보기와 저장이 `shared/filters.ts`의 같은 함수를 쓴다.

## 성능·메모리
- 값이 바뀌면 긴 변 1,200px 축소본으로 즉시 미리보기, 입력이 220ms 멈추면 원본 해상도로 다시 계산한다(최대 1,600만 픽셀 → 약 64MB 캔버스 1장, 현재 사진만 유지). 계산 중에는 기존 블러 패치를 유지해 가린 부분이 드러나지 않는다.
- 저장 때는 원본 해상도로 다시 계산하고 끝나면 캔버스를 해제한다.

## 검증 (macOS 26.3 arm64)
- 단위 4개: 0 값 불변·알파 보존, 노출/대비/채도 방향, 색온도 방향, 값 검증.
- E2E 1개: 슬라이더 드래그 1회 undo/redo, 미리보기 레이어 변경, 모든 사진에 적용 후 두 번째 사진 `수정됨`, 저장 결과에서 사진 픽셀은 보정·스티커 픽셀은 원래 색, 저장하고 다음 후 값 유지, 초기화 undo.
- 큰 사진에서 슬라이더 반응 속도와 Windows 수동 확인은 대기.
