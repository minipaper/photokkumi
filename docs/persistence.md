# 설정 유지 (0.1.3)

사용자 보고(2026-11-09, 0.1.2 Windows 설치본): 출력 폴더 등 직접 고른 값이 앱을 다시 켜면 사라짐.

## 원인
- 출력 형식·크기·품질은 이미 `settings.json`에 저장되고 있었다.
- 출력 폴더는 main 프로세스 메모리(`outputDirectory`)에만 있었고 창이 닫힐 때 지워졌다. 가림 기본값·GIF 옵션은 React 상태뿐이었다.

## 무엇을 어디에 남기나
| 값 | 위치 | 비고 |
|---|---|---|
| 마지막 출력 폴더 | `userData/prefs.json` | 폴더 선택·사진 저장·GIF 저장 때 갱신. 시작 시 폴더가 없으면 버리고 첫 저장 때 다시 묻는다 |
| 마지막으로 사진을 연 폴더 | `prefs.json` | `사진 열기`·`폴더 열기` 대화상자의 시작 위치로만 쓴다(자동으로 열지 않음) |
| 창 위치·크기·최대화 | `prefs.json` | 닫을 때 동기 저장(곧 앱이 종료되므로 비동기 쓰기가 끊기지 않게). 연결된 화면에서 충분히 보이지 않으면(모니터 분리 등) 기본 크기로 연다 |
| 가림 모양·방식·강도 | localStorage `pk.regionDefaults` | |
| GIF 너비·FPS | localStorage `pk.gifWidth`, `pk.gifFps` | 허용 목록 값만 읽음 |
| 위치·크기 숫자 패널 열림 | localStorage `pk.placementFields` | 기존 |

- `prefs.json`: `schemaVersion: 1`, 임시 파일 → rename. 손상·잘못된 값(상대 경로, 비정수·비정상 창 크기)은 기본값으로 읽는다. 편의 설정이라 손상 시 덮어써도 된다(출력 설정·라이브러리와 다름).
- 경로는 main이 대화상자·저장 결과에서만 얻고 renderer는 읽기 전용 `getOutputFolder()`만 쓴다.
- 편집 중인 사진 목록·스티커 배치는 여전히 재실행 후 복원하지 않는다(README 범위 밖).

## 검증
- 단위: `tests/prefs.test.ts` 왕복, 손상 파일, 잘못된 경로·창 크기 거부, 동기 저장 병합·임시 파일 없음.
- E2E 전체 2회 반복 56/56 통과(처음엔 종료 직전 비동기 쓰기가 끊겨 `.tmp`가 남는 실패를 테스트가 잡아 동기 저장으로 고침).
- E2E(`투명 PNG와 반투명…`): 저장 → 가림 사각형·모자이크·강도 70 → 재시작 → 출력 폴더 표시·가림 기본값 유지 → 폴더 대화상자 없이(취소 stub) 저장 완료.
- 창 위치 복원·다중 모니터는 Windows 수동 확인 대기.
